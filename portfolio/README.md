# Andre Jones — Milestone 2 preview

A black, white, and gray glass portfolio with a small JavaScript cursor spotlight. The homepage preserves Andre’s writing and project selection; the catalog, GEMMA details, and sample cart implement the Milestone 2 page designs.

## Canonical course source

The Flask app is in `../submission/ActivityWebserver`. Its independent `project2` templates and static folders keep Milestone 1 unchanged. Business data, estimated code-exploration times, category selection, and time-plan arithmetic are in `app.py`.

Run `python3 -m flask --app app run` from the ActivityWebserver folder, then visit `/project2`. The activity landing page links to both milestones. See `../submission/MILESTONE2-CHECKLIST.md` for requirements and submission steps.

## Hosted static preview

`dist` is generated by `python3 scripts/export_milestone2_preview.py` from the PersonalProject root. It includes the home, catalog, category pages, details, and cart, with relative asset links and a deferred spotlight script. Its cart is a visual sample; Flask performs quantity recalculation in the course submission.

Edit the Flask templates and `static/css/project2/styles.css`, then re-export to update the preview. Do not edit generated `dist` pages separately.

## Verification

Run `python3 scripts/verify_milestone2.py` from PersonalProject. This checks routes, links, images, quantity calculations, validation, and NetID prefixes. Visual checks covered 1440px desktop and 390px mobile; all four required external browsers still need a final course check.

Run `python3 scripts/test_build_workflows.py` for isolated regression checks. These create temporary copies to verify that the retired generator leaves source unchanged and the exporter can rebuild a missing `portfolio/dist` tree with valid local links and responsive image candidates.

`scripts/build_milestone2.py` is retired. It now stops with an explanation and makes no source writes because its historical templates are incompatible with the current time-based app. Maintain the canonical Flask source directly and use `scripts/export_milestone2_preview.py` to regenerate the preview. The exporter creates its output folders automatically.

## Cursor spotlight

`static/js/project2/spotlight.js` tracks mouse movement with animation-frame batching. The shared template loads it with `defer`. White on regular pages; cyan, violet, and rose on Current Project. It does not intercept clicks and is hidden for touch, reduced motion, pointer exit, and keyboard navigation. The static exporter copies it to `dist/spotlight.js`.

## Performance pass

- Replaced oversized JPEG screenshots with 180px, 360px, and 720px monochrome WebP variants. All six variants total 36,334 bytes, versus 335,930 bytes for the two old JPEGs (89.2% smaller). M1 originals are preserved.
- Responsive `srcset`/`sizes`, explicit image dimensions, asynchronous decoding, and lazy loading below the fold reduce unnecessary downloads and layout movement. The details screenshot is prioritized.
- Removed redundant grayscale GPU filters and backdrop blur on static glass panels, while retaining gradients, borders, highlights, and header glass. The moving spotlight no longer needs a blur filter.
- Mouse listeners are registered only for eligible devices. Pointer movement remains batched to one paint per animation frame, without a continuous JavaScript loop.
- Decorative animation pauses offscreen and in hidden tabs, and is static on smaller screens.
- Static export removes HTML comments and redundant whitespace outside preformatted code.
- Complete static files measured 722,564 → 418,118 bytes, including the unchanged resume PDF: a 42.1% file-size reduction. This is not a network-speed or Core Web Vitals benchmark.
- Route, asset, responsive-image, and cart-calculation verification passed; browser review confirmed the optimized screenshot and cursor effect. No runtime framework, external fonts, or new runtime dependencies were added.

To regenerate images, run `scripts/optimize_project_images.py` with the bundled Pillow-enabled Python runtime. Flask itself does not need Pillow. Then run `python3 scripts/export_milestone2_preview.py` to refresh the hosted files.
