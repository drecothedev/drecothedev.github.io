Swim is an experimental Swift compiler tooling project designed to make general-purpose GPU programming feel as natural as writing ordinary Swift.

The goal is to let developers write a Swift function once and execute that same function on either the CPU or GPU, without rewriting its implementation in Metal Shading Language (MSL).

I’m exploring how far Swift’s existing syntax and tooling can extend to support a high-level, expressive GPU programming experience.

In development. Shared CPU/GPU execution is the project’s goal, not a claim of a completed implementation.
